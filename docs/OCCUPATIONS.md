# Occupations

The site publishes **six** occupation profiles plus an index at [pstq.getnorthpath.com/occupations](https://pstq.getnorthpath.com/occupations). They describe a **typical TEER**, the stream the site usually assigns, and a short labour-market caution. They then send you to the calculator.

These pages do **not** print a NOC code. Do not infer one from the job title. Confirm the code in the [NOC 2021 search](https://noc.esdc.gc.ca/) and confirm whether the occupation is regulated in Québec before you rely on the stream.

Every profile includes the same worked-example framing: enter French, work, and diploma in the calculator; the result is a score out of 1,400 that can rank you in Arrima; it does not guarantee an invitation, because each draw sets its own cutoff and that cutoff is not published in advance. Each page also says it does **not** replace an official Québec result. Only Québec issues a selection decision.

Labour-market diagnosis is updated by Québec. The pages tell you to confirm the current designation. A shortage note on these pages is **context**, not a verified point value.

Index README: [pages/OCCUPATIONS.md](pages/OCCUPATIONS.md). Stream rules: [STREAMS.md](STREAMS.md).

## How occupation inputs work on the calculator

The homepage does not ask you to pick one of these six titles. It asks for:

1. **TEER category (NOC 2021)**, which assigns Stream 1 or Stream 2 when the occupation is not regulated
2. **Whether the occupation is regulated in Québec**, which moves the profile toward Stream 3
3. **Labour-market diagnosis category**, which you select to match the official list
4. **Months of experience in that occupation** (the diagnosis factor interpolates under 48 months)
5. **Professional authorization**: a valid permit, or partial or full equivalence recognition

The six articles are explanations of common cases. The score still depends on the values you enter and on the verified vs partial rules in [SCORING-MODEL.md](SCORING-MODEL.md).

## What is not on these pages

- A complete NOC 2021 catalogue
- A guaranteed labour-market diagnosis or a point award for “shortage”
- A promise that Stream 2’s size in recent rounds will continue
- Eligibility for Stream 4. Exceptional talent is self-declared and is not one of these six profiles
