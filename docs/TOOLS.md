## TEF Canada / TCF Canada → French level

Québec scores French on the **Échelle québécoise** (levels 1 to 12), not on the raw test score. The tool asks you to pick a test and enter a score, then shows a level to carry into the calculator.

The page publishes this **comprehension** correspondence. It attributes the table to Québec’s *Tableaux de correspondance* for the PSTQ.

| Level | CEFR | TEF Canada comprehension | TCF Canada comprehension |
| --- | --- | --- | --- |
| 1–2 | A1 | 100–199 | 100–199 |
| 3 | A2 | 200–259 | 200–259 |
| 4 | A2 | 260–299 | 260–299 |
| 5–6 | B1 | 300–399 | 300–399 |
| 7–8 | B2 | 400–499 | 400–499 |
| 9–10 | C1 | 500–599 | 500–599 |
| 11–12 | C2 | 600–699 | 600–699 |

**Status: comprehension bands as published on the tool.** The page says expression (production) scores use a **different scale** and that this tool does **not** convert them reliably. TCF expression often uses another scale. Check the official correspondence table before relying on a production score.

This is **not** the same mapping as federal CLB/NCLC. Use this tool for PSTQ French. Use the CLB page only for federal comparisons.

The calculator still needs all four competencies (oral and written, comprehension and production). A comprehension level does not fill the production fields.

## English test → CLB reference

The page states that English is **not a scored factor** in the PSTQ. The table is there so someone can compare a result with a federal Express Entry profile. It has **no effect** on the calculator.

The site labels the table **reference only** and, on the page itself, **unverified in this pass**. It tells you to cross-check IRCC’s official language-conversion tables before relying on it. Confirm at [IRCC language test results](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/documents/language-test.html).

## NOC and TEER finder

You type an occupation and the tool shows a typical TEER category, which is the main signal for Stream 1 vs Stream 2.

Limits stated on the page:

- It covers **common occupations**, not the full NOC 2021 structure
- For anything not listed, use the official NOC: [noc.esdc.gc.ca](https://noc.esdc.gc.ca/) (NOC 2021 Version 1.0)
- The page points a fuller build at the Statistics Canada **NOC 2021 V1.0** structure and elements files: [statcan.gc.ca NOC 2021 V1.0](https://www.statcan.gc.ca/en/subjects/standard/noc/2021/indexV1)
- **TEER alone does not decide Stream 3.** A regulated profession usually lands in Stream 3 even when TEER would suggest Stream 1 or 2

The six occupation articles are narrative pages, not this lookup. See [OCCUPATIONS.md](OCCUPATIONS.md).

## PEQ closure check

The Programme de l'expérience québécoise (**PEQ**) **closed to new applications in November 2025**. The tool’s point is that the old fast track no longer exists. People who would have used the PEQ now submit an expression of interest through **Arrima** under the PSTQ.

What the page says still scores:

- Québec work experience, up to **160** points
- A Québec diploma, up to **200** points

Those points do **not** bypass Arrima ranking or the invitation process. The tool then sends you to find your stream, run the calculator, and check French gates.

There is a longer comparison at [/guide/pstq-vs-peq](https://pstq.getnorthpath.com/guide/pstq-vs-peq).

## CSQ → federal PR timeline

A **CSQ is not permanent residence**. The page lists three steps and refuses to hard-code a processing time:

1. **Receive the CSQ**, issued after MIFI examines the permanent-selection application that followed an Arrima invitation.
2. **Apply to IRCC for permanent residence.** Separate application, with its own fees, medical exam, biometrics, and security checks.
3. **IRCC processes the application.** The time is set and published by IRCC and changes. The page does not state a number of months.

Check the current figure on [IRCC processing times](https://www.canada.ca/en/immigration-refugees-citizenship/services/application/check-processing-times.html). Those times are IRCC’s estimates, not a promise, and not a figure produced by this calculator.

A CSQ is also **not** an Express Entry provincial nomination and **does not add CRS points**. The FAQ states that Québec selection sits outside Express Entry.
