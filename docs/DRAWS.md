# 2026 Arrima invitation history

The live page is [pstq.getnorthpath.com/draws](https://pstq.getnorthpath.com/draws). It transcribes PSTQ invitation rounds published on Québec’s site. It is **not** a pass mark, and it is **not** a forecast.

**Coverage on the page:** 9 rounds in 2026, through **24 September 2026**. Each round covers all four streams. The page says each round invited roughly **500 to 2,550** candidates in total, and that published score thresholds ranged from **376 to 855** depending on stream and exercise.

Ranges are the **lowest and highest published threshold** across that round’s exercises, not a single cutoff. Stream 4 has **no score published** in every row below. One Stream 2 invitation count is published as **n/a**.

Source the page cites: [Invitations in Arrima for the PSTQ (2026)](https://www.quebec.ca/en/immigration/permanent/skilled-workers/skilled-worker-selection-program/invitation/2026). If a later round appears on quebec.ca and not in the table below, quebec.ca is current. This file matches the calculator site as checked on **6 October 2026**.

A score inside a past range does not mean a future round will invite at that range. The FAQ states there is no fixed pass mark.

## How the calculator uses the latest round

The homepage, on an empty Stream 2 profile, cites the **24 September 2026** Stream 2 floor and the other streams from that same date:

| Stream | 2026-09-24 range on the site |
| --- | --- |
| 1 | 634–706 |
| 2 | 611–706 |
| 3 | 380–697 |
| 4 | No score published |

The message tells you whether the **current estimate** is below that round’s floor. Being below a past floor is context. It is not a determination that a later round will use the same floor.

---

## How to read a row

| Column | Meaning |
| --- | --- |
| Date | The round date published on the draws page |
| Stream | 1 highly qualified, 2 intermediate and manual, 3 regulated professions, 4 exceptional talent |
| Invitations | Count published for that stream in that round. `n/a` means the site did not publish a count for that cell |
| Score range | Lowest to highest **published** threshold across that round’s exercises. “No score published” means the page does not show one. Do not invent a Stream 4 cutoff |

The FAQ says draws have been held **roughly every four to six weeks**, that cadence and the split vary, and that you should not treat “monthly” as a promise. Nine rounds were held in 2026 as of 24 September.

## What this history does not include

- Rounds after 24 September 2026, unless the live page has been updated since this file was written
- A region, occupation, or French-level breakdown inside each exercise
- An official Arrima score for any person
- Eligibility. A score inside a published range can still fail a stream gate
