# Sources

The calculator is an independent reading of public Québec and IRCC material. It is not those institutions’ software. If a number here and an official page disagree, **the official page wins**.

Live methodology: [pstq.getnorthpath.com/methodology](https://pstq.getnorthpath.com/methodology)

This list was checked on **6 October 2026**. Re-check Québec’s invitation page after every round, and re-check the points PDF if the grid is amended.

## Status words

| Status on the methodology page | Meaning |
| --- | --- |
| **Primary** | The site uses this document for the purpose in the table below |
| **Not yet paginated / cited exactly** | The site names the instrument and does not yet give an exact gazette citation. This hub does not invent one |
| **Partial** | A factor inside an otherwise primary document is approximated. See [SCORING-MODEL.md](SCORING-MODEL.md) |
| **Unverified** | Used on the CLB tool only. Not a PSTQ source |

## What is intentionally not sourced here

- A gazette page number, volume, or date line. The methodology page says that citation is not exact yet.
- Cell-by-cell values for partial factors (education field of study, interpolated diagnosis months, incomplete spouse tables, Stream 4 French minimum).
- A labour-market diagnosis for a specific NOC. Occupation pages say the diagnosis changes and must be confirmed on the official list.
- Processing-time months for IRCC.
