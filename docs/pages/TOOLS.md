# Tools hub

**Live:** [https://pstq.getnorthpath.com/tools](https://pstq.getnorthpath.com/tools)

The tools hub introduces **five** helpers: a French-level converter, a CLB reference, a NOC/TEER finder, a PEQ closure check, and a CSQ-to-PR timeline. The page says each tool links into the full calculator when you are ready.

Detail, including the comprehension table and the unverified CLB table: [TOOLS.md](../TOOLS.md).

---

## What you do here

1. Pick the helper that matches the stuck question (French level, federal CLB comparison, TEER, PEQ, or what happens after a CSQ)
2. Read the limit printed on that tool before you copy a number into the calculator
3. Enter only a **French level** from the TEF/TCF tool into the PSTQ score. Do not add CLB points

The hub text for the NOC finder says it does not cover the full NOC 2021 structure.
