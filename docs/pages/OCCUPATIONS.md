# Occupations hub

**Live:** [https://pstq.getnorthpath.com/occupations](https://pstq.getnorthpath.com/occupations)

The occupations hub explains that TEER, regulated status, and labour-market context decide which stream scores you and which French gate applies. It lists **six** scoring profiles and tells you to run the calculator with your real profile.

The profiles do not show a NOC code. Confirm the code before you rely on a stream. Full table: [OCCUPATIONS.md](../OCCUPATIONS.md).

---

## What you do here

1. Open the occupation closest to your main job
2. Note the typical TEER and the stream the page usually assigns
3. Read the labour-market caution. It is not a point award
4. Enter TEER, regulated status, and the current diagnosis yourself on the [calculator](https://pstq.getnorthpath.com/)
