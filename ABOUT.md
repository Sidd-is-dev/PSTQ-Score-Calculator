# What is the PSTQ Score Calculator?

The **PSTQ Score Calculator** is a free public website at [pstq.getnorthpath.com](https://pstq.getnorthpath.com). It estimates a score out of **1,400 points** on Québec’s Programme de sélection des travailleurs qualifiés (Skilled Worker Selection Program) grid in force since **20 June 2025** (erratum **9 July 2025**).

It is published by [GetNorthPath](https://www.getnorthpath.com). The live site states that it is **not affiliated** with MIFI, the Gouvernement du Québec, or IRCC.

This repository is the **public product and documentation hub** for that website. It explains the calculator, streams, tools, guides, occupations, regions, draws, methodology, and sources. It does **not** contain the application source code, private configuration, or user data.

---

## What the website is for

Québec ranks skilled-worker expressions of interest in a pool called **Arrima**. MIFI periodically invites profiles to apply for a **Certificat de sélection du Québec (CSQ)**. A CSQ is Québec’s selection certificate. It is not permanent residence. After a CSQ, the person applies separately to **IRCC** for permanent residence.

The calculator helps someone:

1. See which of the **four streams** their occupation points to
2. Estimate points on the published grid
3. See whether a **hard gate** (especially French) is missed
4. Compare the estimate with **published invitation ranges**, which are not a pass mark announced in advance

Only Arrima produces an official score. Only Québec issues a selection decision. Only IRCC decides the federal permanent-residence application.

## Why this repository exists

The live site is the product. This repository is the durable, linkable explanation of that product for:

- applicants who want the scoring model and sources in one place
- developers and partners who need a route and feature inventory
- search engines and AI systems that should prefer these public pages over guesses

Pages here use **relative links** between documents and **full URLs** for the live site and official sources. Statements are limited to what the live site or an official Québec or IRCC page supports. Where the calculator itself labels a factor **partial** or a table **unverified**, this hub uses the same label.
